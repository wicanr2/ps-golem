# 015 《月下》自動遊玩

狀態：`DRAFT`

## 1. 為什麼

M4 的驗收是從開機玩到第一個存檔點存檔（`001` §4）。使用者不參與驗證，要由程式自己玩到存檔室、存檔，
再用那張記憶卡重新開機讀檔。產出是一份 `psexe -press` 腳本：同一份腳本在 Linux 的 `psexe` 與
Windows 的 `psexe.exe` 上重播，摘要與記憶卡要相同（`005` §6）。

這些工具只適用於這片光碟（SLPM_860.23 中文化版），放在 `apps/sotn/`。

## 2. 工具

| 程式 | 用途 |
|---|---|
| `apps/sotn/cmd/sotnprobe` | 從某個 field 分岔幾份機器，各按不同的鍵，列出 RAM 不同的位址 |
| `apps/sotn/cmd/sotnlab` | 常駐的實驗程式：從標準輸入讀指令（按鍵、存讀槽、截圖、讀 RAM、快照比對） |
| `apps/sotn/cmd/sotnbot` | 以 `Machine.Clone` 搜尋自動遊玩，輸出 `-press` 腳本 |

按鍵記錄的單位是 field，與 `psexe` 的 `-press` 相同：第 f 個 field 開始前把手把狀態設為腳本在 f 的值，
再跑到下一次 VBlank。

## 3. 找位址的方法

從同一個狀態複製幾份機器，各做一件只差一個因素的事（不按、按左、按右；攻擊、不攻擊），
比較 RAM，留下隨該因素單調變化的位址。

## 4. 位址台帳

實體表與狀態結構的位置與 sotn-decomp 記載的美版相同（sotn-decomp 只讀，未搬程式碼）。

| 位址 | 內容 | 推論等級 | 證據 |
|---|---|---|---|
| `0x0733D8` | 實體表起點，每個 `0xBC` 位元組，0 號為玩家 | 強證據 | 0 號 +2 隨按左右單調變化（224→186→149） |
| 實體 +0x02 | X 畫面座標（16.16 定點的整數部分） | 強證據 | 同上；鏡頭捲動時停在 128 |
| 實體 +0x06 | Y 畫面座標 | 假說 | 站立時不變，跳躍待核 |
| 實體 +0x3E | HP | 強證據 | 序章德古拉（80 號）跳起鞭打後 600→568，不攻擊的對照組不變 |
| `0x097BA0` | 玩家 HP（s32） | confirmed | 序章被火球打中 43→29；+4 為上限 50，+8 為心 30（與畫面相符） |
| `0x0973F0`、`0x0973F4` | 玩家在房間內的 X、Y | 強證據 | 隨按左右、跳躍變化，鏡頭捲動時仍連續；與 VGMaps 地圖換算的平台高度相符 |
| `0x0730B0`、`0x0730B4`、`0x0730B8` | 目前房間在城堡地圖上的左、上、右格座標 | 假說 | 兩個房間間來回走動：A 房 14,41,14，B 房 11,40,13，同房間內不變、回到 A 房恢復 |
| 實體 80 號（序章） | 德古拉第一型態，HP 600 | 強證據 | 跳鞭打中後 HP 下降；HP 歸零後劇情進入第二型態 |
| 實體 85–88 號（序章） | 德古拉第二型態的判定，HP 共用，起始 1200 | 假說 | 第二型態出現後這四槽 HP 同為 1200 |

## 5. 搜尋

每個決策點把目前機器複製成多份，平行試動作集合中的每個動作，動作做完後再不按鍵向前看一段，
依該段目標的評分函數取分數最高者，在主機器上執行並記錄按鍵。

序章中 Richter 的 HP 降到 1 時 Maria 現身把 HP 補滿，之後 HP 維持 50（不攻擊閒置 10000 field 觀察），
所以序章的評分不必嚴格避傷。

### 5.1 序章德古拉

| 項目 | 內容 |
|---|---|
| 起點 | 對話結束、戰鬥開始（field 17020，腳本見 §6） |
| 動作 | 不動、左、右、跳、左跳、右跳、鞭、原地跳鞭、轉左跳鞭、轉右跳鞭，各 20 field |
| 向前看 | 60 field |
| 評分 | 10 ×（德古拉 HP 減少）− 40 ×（玩家 HP 減少）− 0.05 × \|與德古拉的 X 距離 − 48\|（鞭長約 48 像素） |
| 結束 | 目標槽 HP ≤ 0（第一型態 80 號；第二型態 85–88 號取最小值） |

### 5.2 路線來源

搜尋只看分數，走不出需要先下坡再上坡的路線（人魚池耗盡 HP 後 GAME OVER）。所以入口區的路線依
公開攻略與地圖決定，再在 `sotnlab` 逐段操作驗證：

- Level Winner 攻略第 1 部：存檔室在大廳爬平台後、紅色骷髏劍士左邊的房間。
- VGMaps 的入口區地圖（`Castlevania-SymphonyOfTheNight-Dracula'sCastle-Entrance.png`）：
  由已走過房間的地圖格座標（大廳 4,40、B 房 11–13,40、A 房 14,41）對齊，每格 256 像素。
  只在本機下載閱讀，不進版控。

腳本：`apps/sotn/testdata/m4-first-save.press`（psexe `-press` 格式，空白記憶卡開機，到 field 45784）。
回歸測試：`apps/sotn` 的 `TestM4FirstSave`（`PSGOLEM_LONG=1`）。

| 項目 | 結果 |
|---|---|

| Windows `psexe.exe`（v0.1.1，Wine 9） | 摘要、記憶卡、最後畫面與 Linux 逐位元相同 |
