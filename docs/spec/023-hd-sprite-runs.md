# 023 HD 精靈繪圖序列替換

狀態：`READY`。本規格提供作品中立的可選繪圖附件，沿既有 HD 貼圖路徑，不改鏡頭與遊戲狀態。

## 來源與邊界

既有016／018／019與`render/hd/{gp0,draw,texture_tracking,shadow,raster_state}.go`已核實：命令依序送入影子；8×8原始精靈使用0x65及四個字；原生來源由快取origin追蹤，PNG索引可依原CLUT繪製；CPU／GPU共用lookupTexture。只讀這條影子路徑，不改機器、原生GPU或鏡頭。

作品專屬序列、字形與翻譯由各素材包保存，不放通用核心。

## 可選附件

019的manifest v1保持。素材包可另有`sprite-runs.json`，UTF-8，最多1MiB，嚴格拒絕重複、未知或大小寫別名欄位、null與尾隨JSON。不存在時完全沿用舊路徑；存在但無效則整包拒絕。路徑與PNG沿019守門。

根物件為`version:1`、`runs:[]`。最多64個規則。每條含唯一`id`、`upload_sha256`、原始`width_words`／`height`、`tpage:[x,y]`、`offset:[x,y]`、`buffer_y256`、`image_width`／`image_height`、`scale`、索引PNG的`image`與`steps`。原生來源為4bpp。畫布最多256×256、倍率1／2／4／8，索引0至15。每步含四字`words`、原上傳圖素`source:[x,y]`與畫布原生圖素`image_offset:[x,y]`；僅接受0x65000000、8×8、同一CLUT位址、最多32步。裁切畫布外填索引0，容許附標步取空白。首步命令不得有歧義。附件編成每步不可變8×8索引圖，與019整包共用256MiB解碼上限，不另提高資源界線。

## 匹配、來源與回退

只在4bpp、原始貼圖啟用、無翻轉、無貼圖視窗、TPage與offset相同時匹配。每字精確比較；`buffer_y256`開啟時只容許整列一致的目的Y+256，不改其他位元。起始至完整序列間至多保留32個已完成精靈封包；不同命令先原樣沖出，再處理新命令，不吞命令。例外僅限完全等於目前有效狀態的E1，以及已為零的E2=0xe2000000：先驗證序列環境，原樣執行這兩種無狀態改變命令並保持序列；E1須精確包含目前TPage、ABR、dtd、dfe與翻轉，不容許停用或保留位元。這兩種操作不清貼圖／CLUT快取、不繪製，與待執行精靈可交換。改變任一有效位元仍先沖出，不能略過未知命令。此勘誤在實作前READY。

完整匹配後，依原第一命令載入CLUT，要求索引0透明。在私有貼圖快取副本模擬每步8×8原取樣，逐點核對原始上傳鍵、尺寸、有效來源字及相對來源座標。私有快取不改真實cache引用、字或統計；VRAM讀取沿原texel的GPU相依守門。任一步不符即全部原樣繪製。來源驗證不把未知資料猜成已知。

通過才逐步經原execute／drawSprite／lookupTexture路徑繪製替代圖，原命令、CLUT、混色、遮罩、裁切與GPU路徑保持。字格外原畫布空白使附標消失。完成後立即清除每步覆寫，不改全域字圖；原生CPU／GPU輸入與狀態不受影響。

GP1、field、觀測field、畫面／VRAM／統計／Fence讀取及Close前，未完成序列一律原樣沖出，不能跨同步界線延遲繪製。包內缺附件不配置序列狀態。附加統計獨立回傳匹配及回退數，不改既有TextureStats欄位。

## 驗收與停止線

合成來源測載入、未知／重複欄位、路徑、維度／索引／上限、完整匹配、破損來源、錯序、截斷、GP1／Field／Screen／Close邊界與可選256列。無附件／未匹配須沿舊像素與來源快取行為；同不可變包可供多個獨立影子使用。HD套件回歸與race通過。

實際素材的驗證由素材專案保存。通用核心使用合成資料核對 CPU／GPU、來源守門與精確回退。單獨繪圖重播不聲明 CPU／RAM 同場或遊戲效能。

本層入口為`render/hd/sprite_runs.go`，從`LoadTexturePack`選用載入，不新增產品操作。沒有附件的包可由舊、新程式讀取；帶附件的包需本規格程式，舊程式會忽略附件，不能當作中文已接入。工作歷程放唯一WORKLOG，索引放000。
