# 004 CPU（R3000A）

狀態：`CONFORMED`（2026-10-15）

## 1. 範圍

MIPS I 整數指令、load delay slot、branch delay slot、COP0 例外與中斷、
隔離快取寫入（BIOS 用來清快取）。記憶體映射見 `006-minimal-machine`，匯流排時序另立規格。

套件：`internal/cpu/`。主要參照 `beetle-psx-libretro` 的 `mednafen/psx/cpu.c`
（commit `e57860d82faa953dc0fc10f201fd583739bc2f7d`，GPL-2.0-or-later）。

## 2. 驗收語料

沒有逐指令、實機產生的 R3000A 語料（2026-10-15 以網路與 GitHub 搜尋查過），
所以 CPU 在最小機器上以實機測試程式驗收：

| 語料 | 授權 | 結果 |
|---|---|---|
| ps1-tests `cpu/cop` | MIT | 與 `psx.log` 相同 |
| ps1-tests `cpu/code-in-io` | MIT | 與 `psx.log` 相同 |
| ps1-tests `gte/test-all`（經 COP2 指令） | MIT | 與 `psx.log` 相同 |
| ps1-tests `cpu/io-access-bitwidth` | MIT | 週邊台帳，見 `006-minimal-machine` §7.1 |
| ps1-tests `cpu/access-time` | MIT | 未驗收，屬週期模型 |
| amidog `psxtest_cpu`、`psxtest_cpx` | zip 條款未寫；wiki 為 CC BY-NC-SA 3.0 | 未跑；只抓進 `testdata/` 本機用 |

比對規則與執行方式見 `006-minimal-machine` §7。兩個 BIOS（SCPH5500 v3.0、SCPH-100 v4.3）結果相同。

## 3. 與參照實作的差異

依實機紀錄修正：

| 行為 | 參照實作 | 本實作 | 證據 |
|---|---|---|---|
| COP2 停用時的 SWC2 | 不檢查 | 丟協處理器不可用例外 | `cpu/cop` testSwc2Disabled 實機為 pass（confirmed） |
| COP2 停用時的 LWC2 | 不檢查 | 比照 SWC2 | 無直接證據（假說） |
| 從 scratchpad、MDEC、中斷控制器取指令 | 不處理 | 指令匯流排錯誤 | `cpu/code-in-io`（confirmed），見 `006` §4.1 |

LWL／LWR／SWL／SWR 讀寫整個字再合併，參照實作是對 I/O 發出部分寬度的存取。
兩者對 RAM 結果相同，對 I/O 可能不同；屬匯流排規格的範圍。
